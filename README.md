# 🛒 Nxt-Trendz - E-Commerce Clone (Amazon / Flipkart)

Nxt-Trendz is a React-based e-commerce web application that allows users to browse, search, and filter products. It is a **frontend-focused project** designed to simulate an online shopping experience similar to Amazon or Flipkart. The application is fully responsive and features a modern, user-friendly interface.

## ⚙️ Features

### 👥 User Features
- 📝 Login / Signup / Logout (Frontend simulation)
- 🔍 Search Products by Name
- 🛠️ Filter Products by Category and Subcategory
- 📦 View Product Details including Price, Description, and Ratings
- 🛒 Add / Remove Products from Cart (Frontend simulation)
- 📱 Fully Responsive Layout
- 💡 Clean & User-Friendly Interface

---

## 🔧 API Integration

- ✅ Fetch products, categories, and product details via REST APIs
- ✅ Add / Remove / Update cart items via REST APIs
- ✅ Simulated authentication using JWT

## 🧰 Tech Stack

| Technology       | Purpose                        |

| **React.js**     | Frontend UI Framework          |

## 🚀 Getting Started

### 📦 Installation

1. **Clone the repository**
```bash
git clone https://github.com/chintpradeep22/Nxt-Trendz.git
cd Nxt-Trendz
```
2. **Install dependencies**
```bash
npm install
```
3. **Start the application**
```bash
npm start
```
